产品需求文档（PRD）

版本规范：语义化版本 SemVer
当前版本：v0.1.0-alpha.1
技术栈：Rust + Tauri
支持平台：Windows / macOS / Linux（当前版本已完成 macOS，Windows/Linux 开发中）

1. 产品定位

跨平台轻量级桌面 GUI 工具，用于可视化安装、更新、卸载 Claude / Gemini / Codex 等 AI 终端工具，并统一管理 MCP（Model Context Protocol）与 Skills 插件体系，支持多工具间配置共享与快速切换，避免重复安装与重复配置。

2. 背景与痛点

• 安装、更新、卸载流程分散，工具间缺乏统一入口
• 不同操作系统差异大，学习成本高
• MCP、Skills 等通用能力需要重复配置
• 多工具切换时环境不互通，效率低
• 缺少可视化管理与可追踪的操作日志

3. 目标用户

• 后端/前端开发者、AI 工具重度用户
• 频繁在多个 AI 终端工具间切换的用户
• 追求环境整洁与稳定交付的技术人员

4. 目标与成功指标

• 统一安装/更新/卸载入口，降低学习成本
• 关键路径可追踪、可回滚、可重试
• 启动时间：冷启动 < 1.5s（目标）
• 单次安装成功率：> 99%（目标）
• 操作失败可恢复：失败后可再次执行且不会残留脏状态

5. 范围边界

5.1 本期范围（v0.1.0-alpha.1）

• Claude CLI、Gemini CLI、Codex CLI 的安装/更新/卸载（macOS）
• 状态与版本信息展示
• 下载与操作日志展示（默认开启日志落盘，保留 7 天，可手动清理）
• 设置页（通用/代理/关于）

5.2 非本期范围

• MCP 全局配置管理
• Skills 全局配置管理
• 仓库源管理与第三方源
• 配置备份/导入/导出
• 多套配置方案切换

7. v0.1.0-alpha.1 核心功能

7.1 工具管理

• 展示 Claude、Gemini、Codex 三个工具
• 状态标识：未安装 / 已安装 / 可更新
• 一键安装
• 一键更新至最新版本
• 一键卸载
• 自动识别操作系统

7.2 状态展示

• 当前安装版本号
• 最新可用版本
• 可执行文件路径（主展示）
• 配置路径（高级信息）
• 实时操作日志（默认落盘，保留 7 天，可手动清理）

7.3 基础体验

• 下载进度条
• 成功/失败提示
• 简洁直观的操作界面
• 稳定、无崩溃

8. 用户流程

8.1 安装流程

1. 识别系统与目标工具版本
2. 下载并校验包
3. 解压并写入可执行文件路径
4. 更新状态与日志

8.2 更新流程

1. 检测最新版本
2. 下载并校验包
3. 替换旧版本
4. 更新状态与日志

8.3 卸载流程

1. 删除安装文件
2. 清理本地配置（若存在）
3. 更新状态与日志

9. 功能验收标准（v0.1.0-alpha.1）

• 能正确识别三类工具的安装状态与版本
• 安装/更新/卸载成功后，状态、版本、路径一致且可复现
• 失败后可重试且不会残留半安装状态
• 日志可追踪核心操作步骤并包含失败原因（支持落盘与清理）

10. 非功能需求

• 启动快速、体积轻量
• 不污染系统环境
• 下载文件完整性校验（后续版本）
• 不收集用户隐私
• 合理申请系统权限

11. 兼容性与限制

• Windows/macOS/Linux 的主流发行版
• 不保证对历史版本 OS 的兼容
• 仅支持官方发布源

12. 风险与依赖

• 上游 CLI 发布渠道变更导致安装失败
• 安装包格式变化导致解压逻辑失效
• 系统权限不足导致写入失败

13. 界面结构

• 顶部：应用名称 + 系统/网络状态 + 任务概览与入口
• 主体：三个工具卡片（Claude / Gemini / Codex）
• 每个卡片：状态 + 版本 + 操作按钮
• 日志：日志弹窗（支持落盘与清理）
