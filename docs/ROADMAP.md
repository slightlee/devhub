# Roadmap

本文档描述 DevHub 的版本节奏和交付目标，用于公开协作对齐。

## 版本节奏

## `v0.1.0-alpha.1`（当前）

- 支持 Claude CLI / Gemini CLI / Codex CLI 的安装、更新、卸载（macOS 已完成）
- 提供基础状态展示与任务反馈
- 完成 macOS 端核心流程打通

## `v0.1.0-alpha.2`

- 实现 Windows 端 Claude CLI / Gemini CLI / Codex CLI 安装、更新、卸载
- 优化下载、校验、解压流程稳定性
- 完善 PATH 写入与冲突处理
- 强化错误提示与失败重试体验

## `v0.1.0-beta.1`

- 引入 MCP 基础管理能力
- 引入 Skills 基础管理能力
- 支持多工具共享配置并可切换

## `v0.1.0`

- 稳定版发布
- 完成核心功能回归与体验打磨
- 完善公开文档与开发协作流程

## `v0.2.0+`

- 支持更多 AI CLI 工具
- 支持配置导入导出与备份
- 支持第三方源与插件生态扩展

## 发布门槛（最小）

- 核心流程（安装/更新/卸载）可复现
- 失败可重试且无脏状态残留
- 关键路径有明确日志与错误上下文
